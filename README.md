# WhatsApp Group Chat Oracle 🔮

A modern, multimodal WhatsApp group chat analyzer. Reconstructs group dynamics, mining inside jokes, uncovering secret alliances, transcribing voice notes, analyzing photos, and calculating response latencies and talk-time shares.

## 🚀 Live Web App
Open the live portal on any device:
**[https://nachmantzuf.github.io/whatsapp-chat-oracle/](https://nachmantzuf.github.io/whatsapp-chat-oracle/)**
(Also available on [https://nachmantzuf.github.io/oracle/](https://nachmantzuf.github.io/oracle/))

## Features
- **100% Client-Side or Backend-Powered:** Works instantly in any browser via JSZip or locally with Python + Faster-Whisper.
- **Multimodal Intelligence:** Transcribes voice notes (`.opus`/`.ogg`/`.m4a`) and analyzes shared photos (`.jpg`/`.png`).
- **Slang & Group Archetypes:** Generates sharp, humorous Israeli street slang diagnoses for every member.
- **The Two Extremes:** Highlights the single longest voice note (unlicensed podcast) and longest text message (PhD thesis).
- **Mobile-First Design:** Optimized for iOS Safari, Android Chrome, tablets, and desktop.
- **One-Click Full Print:** Clean `@media print` layout for exporting full PDF dossiers.

## Local Execution
```bash
python server.py 8090
```
Then open `http://localhost:8090/`.
